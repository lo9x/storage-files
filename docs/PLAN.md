# План работ на 4 недели

Проект: **Storage Files — облачное хранилище** (тема № 2).
Стек: ASP.NET Core MVC + EF Core + SQLite + Bootstrap.

## Неделя 1 — фундамент и аккаунты ✅

- [x] Создать solution и MVC-проект, подключить EF Core и SQLite.
- [x] Спроектировать схему БД: `Users`, `Folders`, `Files`.
- [x] Настроить `AppDbContext`, миграции и сидер администратора.
- [x] Реализовать регистрацию, вход, выход (cookie-аутентификация).
- [x] Хеширование паролей, роли `User` / `Admin`.
- [x] Базовый layout: боковая панель, индикатор занятого места, сообщения об ошибках.
- [x] Landing-страница и адаптивные стили.

## Неделя 2 — файловый менеджер ✅

- [x] Загрузка файлов на диск под случайным именем, запись метаданных в БД.
- [x] Создание, переименование и перемещение папок; навигация по вложенности.
- [x] Скачивание, переименование и перемещение файлов.
- [x] Мягкое удаление файлов и папок, корзина с восстановлением и очисткой.
- [x] Поиск по имени и сортировка по имени / размеру / дате.
- [x] Проверка лимита хранения при загрузке и восстановлении.
- [x] Проверка владельца во всех запросах (чужие данные → 404).
- [x] Валидация имён, размеров и форм; защита POST-запросов anti-forgery токеном.

## Неделя 3 — общий доступ (план)

- [ ] Таблица `ShareLinks`: токен, владелец, файл/папка, пароль, срок действия.
- [ ] Публичная страница `/s/{token}` без авторизации.
- [ ] Настройка срока действия и пароля для ссылки.
- [ ] Скачивание файла и просмотр содержимого папки по ссылке.
- [ ] Отзыв ссылки владельцем, список активных ссылок.
- [ ] Проверка истечения срока и пароля, ограничение доступа.

## Неделя 4 — администрирование и сдача (план)

- [ ] Админ-панель: список пользователей, занятое место, изменение лимита.
- [ ] Запрет входа заблокированным пользователям (при необходимости).
- [ ] Dockerfile / docker-compose для запуска одной командой.
- [ ] Модульные тесты ключевой логики (лимиты, доступ, имена).
- [ ] ER-диаграмма, описание API, инструкция по запуску — актуализировать.
- [ ] Скриншоты и сценарий демонстрации на защите.

## Критерии готовности проекта

- Рабочий интерфейс и серверная часть.
- База данных с продуманной структурой и связями.
- Регистрация, авторизация, роли.
- Основные функции темы: файлы, папки, поиск, общий доступ, корзина, лимиты, админка.
- Обработка ошибок и валидация ввода.
- Адаптивный интерфейс.
- Репозиторий, ER-диаграмма, описание API, инструкция по запуску, демонстрация.
